Mapa da stack do Grana

Use esta página para localizar uma responsabilidade antes de avaliar uma mudança.

Ambiente

Navegador

Executa o JavaScript, desenha a interface e recebe as interações do usuário.

Construção

Vite

Serve o projeto durante o desenvolvimento e produz os arquivos otimizados de produção.

Segurança estrutural

TypeScript

Verifica relações e formatos antes de o JavaScript chegar ao navegador.

Apresentação

Vue 3

Transforma o estado atual em componentes visíveis e reage a eventos.

Estado

Pinia

Centraliza dados compartilhados, valores derivados e ações da feature.

Estilo

Tailwind CSS

Compõe aparência, espaçamento, layout e adaptação responsiva.

Componentes

shadcn-vue + Reka UI

Fornece componentes cuja implementação pertence ao projeto; Reka sustenta comportamentos acessíveis.

Pergunta de localização

  • Mudou o que aparece? Procure Vue e os modelos de tela.
  • Mudou como os dados da sessão evoluem? Procure Pinia.
  • Mudou apenas aparência ou responsividade? Procure Tailwind CSS.
  • Mudou um diálogo, botão ou seletor reutilizável? Procure shadcn-vue.
  • Mudou build, servidor local ou empacotamento? Procure Vite.
  • Mudou um contrato ou formato permitido? Procure TypeScript.
