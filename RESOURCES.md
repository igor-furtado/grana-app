# Arquitetura do Grana Web — Recursos

## Knowledge

- [MDN: How the web works](https://developer.mozilla.org/en-US/docs/Learn_web_development/Getting_started/Web_standards/How_the_web_works)
  Visão confiável de navegador, cliente, servidor e arquivos web. Use para: entender onde a aplicação executa e o que muda quando um backend for introduzido.
- [Vue: Introduction](https://vuejs.org/guide/introduction.html)
  Introdução oficial a componentes, templates, reatividade e Single-File Components. Use para: entender a camada de interface.
- [Vue: State Management](https://vuejs.org/guide/scaling-up/state-management.html)
  Guia oficial sobre estado local, compartilhado e gerenciamento com Pinia. Use para: avaliar onde um dado deveria viver.
- [TypeScript Handbook](https://www.typescriptlang.org/docs/handbook/intro.html)
  Explica o TypeScript como verificador estático de programas JavaScript. Use para: entender quais erros ele previne antes da execução.
- [Vite: Getting Started](https://vite.dev/guide/)
  Documentação oficial do servidor de desenvolvimento e da geração dos arquivos de produção. Use para: distinguir ferramenta de construção de código da aplicação.
- [Pinia: Getting Started](https://pinia.vuejs.org/getting-started.html)
  Fonte oficial sobre stores Vue e estado compartilhado. Use para: compreender state, getters e actions.
- [Tailwind CSS: Styling with utility classes](https://tailwindcss.com/docs/styling-with-utility-classes)
  Explica como utilitários visuais compõem layout, aparência e estados. Use para: reconhecer mudanças estritamente visuais.
- [Tailwind CSS: Responsive design](https://tailwindcss.com/docs/responsive-design)
  Referência oficial sobre adaptação do layout a diferentes larguras. Use para: avaliar comportamento responsivo.
- [shadcn-vue: Introduction](https://www.shadcn-vue.com/docs/introduction.html)
  Mostra como os componentes Vue são adicionados como código-fonte sobre primitives do Reka UI. Use para: entender propriedade, composição e personalização dos componentes.

## Wisdom (Communities)

- [Vue Discussions](https://github.com/vuejs/core/discussions)
  Discussões públicas do projeto Vue. Use futuramente para: observar dúvidas arquiteturais reais e como mantenedores e praticantes raciocinam sobre elas.
