# Notas de ensino

- Ensinar em português brasileiro.
- O usuário começa sem conhecimento de Vue ou da stack web atual; os modelos mentais aprendidos com React e Redux devem ser aproveitados como conceitos transferíveis.
- Priorizar arquitetura, responsabilidades e integração; evitar aulas de sintaxe sem uma dúvida concreta.
- Usar o Grana Web e especialmente o fluxo de transações como exemplos recorrentes.
- O objetivo é avaliar agentes, não desenvolver funcionalidades de forma independente nesta fase.
