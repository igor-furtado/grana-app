# Mudança da stack para Vue 3

O usuário escolheu Vue 3 por considerar a organização dos Single-File Components mais clara para acompanhar e avaliar o trabalho dos agentes. React e Redux Toolkit foram substituídos por Vue 3 e Pinia; os conceitos já aprendidos continuam válidos, mas mudam os nomes e os mecanismos concretos.

O novo mapa equivalente é: Vue recebe a interação e atualiza a apresentação; Pinia mantém o estado compartilhado em memória; Tailwind descreve a aparência; shadcn-vue fornece componentes de código próprio sobre primitives acessíveis do Reka UI; TypeScript verifica contratos; Vite serve e empacota a aplicação.

## Evidence

O usuário comparou a organização de código entre React e Vue, explicitou preferência por Vue 3 e autorizou a troca imediata da stack, condicionando a biblioteca visual à avaliação das opções nativas do ecossistema.
