# Triage Labels

As skills usam cinco papéis canônicos de triagem. O GitHub Issues deste repositório utiliza os mesmos nomes.

| Papel canônico    | Rótulo no GitHub  | Significado                           |
| ----------------- | ----------------- | ------------------------------------- |
| `needs-triage`    | `needs-triage`    | Requer avaliação do mantenedor        |
| `needs-info`      | `needs-info`      | Aguarda informações adicionais        |
| `ready-for-agent` | `ready-for-agent` | Está especificada e pronta para agente |
| `ready-for-human` | `ready-for-human` | Requer implementação humana           |
| `wontfix`         | `wontfix`         | Não será implementada                 |

Quando uma skill mencionar um papel de triagem, use o rótulo correspondente desta tabela.

Se o vocabulário do tracker mudar, atualize a coluna “Rótulo no GitHub”.
