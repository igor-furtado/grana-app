# IDs estáveis para catálogos locais semeados

Categorias padrão e instituições padrão permanecem como seed local do app, mas passam a usar IDs estáveis e versionados pelo produto em vez de UUIDs aleatórios por instalação. Isso preserva referências consistentes entre dispositivos quando registros sincronizados pelo PowerSync apontarem para catálogos locais que não são replicados pelo backend.
