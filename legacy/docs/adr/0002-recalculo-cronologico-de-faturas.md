# Diferenças de fatura ficam visíveis para reconciliação

Correções em datas, compras, créditos ou pagamentos podem deixar uma fatura com
pagamento excedente ou diferença pendente. O produto preserva os vínculos
originais e mostra a diferença para ajuste do usuário, em vez de redistribuir
pagamentos ou créditos automaticamente para esconder a divergência.
